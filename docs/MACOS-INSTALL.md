# Install Pulse 1.6.0

Quit Pulse, open **Pulse-1.6.0.dmg**, and drag **Pulse.app** into **Applications**.

This build includes the latest stacked timeline, scrolling date rail, collapsible inspector and streamlined toolbar.

Apple Silicon Mac, macOS 11 or later, and Python 3.10 or later are required. PDF extraction dependencies are included. Python, Ollama and model weights are installed separately. The app is ad hoc signed and has not been notarized by Apple.

Your existing library remains in your user profile. The installer does not include personal papers or account credentials.

Mendeley RIS export works now. Shared sign-in and library sync require the Pulse owner's application registration and HTTPS hosting and are unavailable in the default installer. See **MENDELEY-ACTIVATION.md** for the owner's remaining activation steps.

# Open PDF preview and local copies

Use **Read PDF** in the paper-details sidebar. A retained PDF opens locally, including offline. If no local copy is available, Pulse checks the paper's full-text links and queries OpenAlex and Europe PMC concurrently. A configured contact email enables Unpaywall lookup as well. Known arXiv links are supported. A missing local attachment can also fall back to open-PDF discovery.

PMC copies also resolve through the current public NCBI Cloud dataset. Pulse lists the article's versioned metadata, verifies the PMCID and DOI, and uses the returned PDF URL. This provides an actual repository file when a publisher or the Europe PMC website blocks anonymous automated downloads. It does not use browser cookies or bypass a website challenge. The 2026 dataset structure is documented in [NCBI's cloud guide](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/) and [dataset README](https://pmc-oa-opendata.s3.amazonaws.com/README.txt). Source failures distinguish blocked automated access from a missing open copy.

Identifier lookups require an exact DOI, OpenAlex ID, PMCID or PMID match. A title-only OpenAlex lookup requires a unique exact normalized title and matching author/year metadata when present; short, uncorroborated or ambiguous titles are rejected. The original paper record is not rewritten by preview discovery. Open landing pages can provide explicit citation PDF metadata, typed PDF alternate links, or PDF anchors containing that article's identifier. Generic links to cited papers are not followed as the article's PDF.

The reader labels an online copy **Preview**, shows its source, and keeps annotation controls unavailable. Page images are rendered by the bundled PDF engine, so publisher framing restrictions do not prevent an accessible PDF from being displayed in Pulse. **Download & annotate** retains a copy in the local profile, saves its attachment reference, downloads the original file through the browser/native Downloads flow and enables local editing. Reopening uses the retained copy.

The PDF reader starts with the Select tool and the right properties panel closed. Only **Properties & comments** opens the panel; choosing a tool does not. The map’s paper-details panel also starts closed; selecting a paper or using **Show paper details** opens it.

The reader scrolls continuously through the whole document. Every page keeps its size in the scroll, and only pages near the screen are rendered, at the current zoom and the screen's pixel density, so text stays sharp on Retina displays. Zoom offers Fit width, Fit page and 50–300%, the − and + buttons, Cmd/Ctrl with +, − or 0, and Ctrl/Cmd+scroll or a trackpad pinch, keeping the point under the pointer in place. The page box, arrows and thumbnails jump to a page; ← and → move one page, ↑ and ↓ scroll, Page Up/Page Down and Space (Shift+Space backwards) move a screen at a time, or a page in Fit page mode, and Home/End go to the first or last page. Each PDF reopens at the page and position where it was left, kept in this computer's app storage; a quotation, evidence or annotation link still opens its own page.

The left pane's **Contents** tab lists the PDF's bookmarks. For PDFs without bookmarks, Pulse builds the list from section headings recognised by type size, weight and common section names, and says so. The current section is marked. Links inside the paper work: citations and cross-references jump to their target page and position, and web and DOI links open in the browser. Other link actions in a PDF, such as opening files or running scripts, are ignored. Links are inactive while a drawing, text or comment tool is selected.

Annotation works directly on the page, as in Acrobat. Round tool bubbles float at the bottom of the reader: Select, Highlight, Underline, Strikethrough, Comment, Add text, Pen, Rectangle and a Page menu (rotate, move or remove the current page). A drawing or text tool shows floating colour swatches and a size control. Selecting text with the Select tool shows a bubble bar with Highlight, Underline, Strikethrough, Comment, Quote to Notes and Copy. With the Comment tool, click the page and type in the popup, then choose **Post** or press Cmd/Ctrl+Enter. Click a comment pin to edit or delete it. With Add text, click the page and type; clicking elsewhere or Cmd/Ctrl+Enter places the text, and Escape cancels. Escape also returns from any tool to Select. Previews offer Select and Copy only until a local copy is downloaded.

The reader also has lazy page thumbnails and document-wide text search with navigable results. Drawing, placing text or comments, and selecting text work on whichever page is under the pointer. Local copies support highlights, underlining, strikethrough, point comments, text boxes, pen drawings and rectangles. Page tools rotate, reorder and exclude pages from an edited copy. Undo/redo covers markup and page changes; draft edits persist in the local attachment record. Text tools add content and markup rather than reflowing existing paragraphs.

**Export edited PDF** creates and downloads a separate PDF containing native PDF annotations and the chosen page order and rotations. The source file stays byte-for-byte unchanged; existing note and evidence links continue pointing to source pages. **Download original PDF** returns the original bytes. Preview files cannot be exported as edited copies until explicitly retained. Export is validated server-side, bounded, and rejects invalid coordinates, page orders, rotations and edit types. Existing PDF forms and signatures are not an editing workflow offered by this release.

Downloads are anonymous public HTTPS requests with no browser cookies, institution sessions or Pulse account credentials. Every redirect is checked, private/local destinations are blocked and the validated destination is pinned for the TLS connection. HTTP links in older index records are upgraded to HTTPS; redirect downgrades are rejected. PDF size, page count, redirects, request time and cache size are bounded. HTML/login/access-denied responses are not treated as PDFs. Pulse does not unlock paywalls, submit login forms or bypass bot challenges; use **Open paper** or attach a copy if automated public access is unavailable.

Preview bytes are needed for page rendering and are held in a private temporary cache, separate from retained attachments. Cache entries expire after 24 hours and are removed on access or later cache maintenance; new previews enforce a 256 MB limit. Preview files never become library attachments until the user chooses download. PDF files, annotations and attachment references remain excluded from relay sync. Public provider queries send the identifiers, title or author/year information needed to identify the paper, not its notes or private full text.

The paper-details action buttons wrap into rows, long citations/keywords/quotations wrap within the panel, and both the detail panel and PDF annotation sidebar scroll vertically.

`npm run test:pdf-viewer` covers continuous scrolling, lazy and sharp rendering, every zoom control, keyboard paging, contents, links, remembered positions, per-page drawing and selection, the selection bar, inline comments and text, and editable comment pins. `test_pdf_viewer.py` covers page sizes, bookmarks, heading-based contents, rotated and filtered links, and zoom render limits. `npm run test:pdf-preview` covers actual page images, preview paging, protected downloads, read-only enforcement, promotion to a retained copy, text search, text boxes, drawing, comments, undo/redo, page changes, edited-file inspection, offline reopening, unavailable PDFs, stale requests and narrow sidebars. `test_pdf_access.py` covers public-network transport, redirects, size/access failures, identity matching, landing-page extraction, preview expiry and preservation of saved copies. `test_pdf_editor.py` checks exported native annotations, source preservation, page order/rotation, read-only enforcement, thumbnails, search and current cloud metadata identity matching. Provider formats: [OpenAlex open-access locations](https://help.openalex.org/data/works/open-access/), [Europe PMC REST API](https://europepmc.org/RestfulWebService), [Unpaywall API](https://data.unpaywall.org/products/api) and [location fields](https://unpaywall.org/data-format).

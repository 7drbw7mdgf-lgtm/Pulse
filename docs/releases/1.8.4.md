# Pulse 1.8.4 — faster first results and resilience to OpenAlex limits

## Faster searches
- **Results appear while sources are still answering.** As soon as the citation searches finish, Pulse shows a preliminary ranking and keeps updating it as slower keyword sources arrive. Papers already on screen stay in the list. The final ranking is still computed once over the full pool, so final results are unchanged.
- **Early settling restored.** Pulse stops waiting for slow long-tail sources once the citation-led top 50 is stable.
- **Pre-warm on selection.** When a paper stays selected for 1.5 s, Pulse runs the search's own collection step in the background with your current options, then pre-computes the offline ranker's scores for the shortlist. A search started after it finishes is served from cache. It never runs during a search, runs at most 10 times an hour, and is skipped while OpenAlex is rate-limited or reports fewer than 300 requests left for the day.

Measured on the 5 benchmark seeds (Apple Silicon, empty profile, one run each):

| | First results visible | Full search |
|---|---|---|
| Cold (nothing cached) | 2.1–4.3 s (median 2.5) | 7.8–13.5 s (median 9.8) |
| After pre-warm finished | 0.0–2.0 s | 2.2–3.8 s (median 2.9) |

Must-find papers in the top 20 / 50 / 200 were 14 / 21 / 54 in every run, the same as 1.8.3. Pre-warm itself takes about 8–12 s, and a pre-warm followed by the search uses about 33 OpenAlex requests (a cold search alone uses about 17). The planned 20-seed timing run has not been done yet because of OpenAlex's daily limit.

## When OpenAlex is limited
- **Longer cache for stable lookups:** single papers, citing papers and reference lists are cached for 7 days; free-text searches stay at 15 minutes. The cache is compressed and stores no credentials.
- **Keyless citation fallbacks:** when OpenAlex is paused, citation searches use Europe PMC, then NIH iCite, then OpenCitations, and record which provider found each paper.
- **Visible notice:** the discovery view says when OpenAlex is limited and until what time; other sources continue.
- **Optional OpenAlex API key** in Settings, stored encrypted like other keys. It is sent as OpenAlex expects (a query parameter) and is removed from cache keys and stored URLs. A contact email, if set, is sent for OpenAlex's polite pool.

The Windows installer remains 1.8.0. The Apple Silicon package keeps its macOS 11+ target, PDF support and persistent offline ranker. The main backend requires Python 3.10+. The app is ad hoc signed and not Apple-notarized.

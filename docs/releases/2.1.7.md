# Pulse 2.1.7

Pulse 2.1.7 introduces deep topological graph analytics, systematic review screening with PRISMA 2020 compliance, section-targeted evidence extraction with consensus synthesis, and high-performance two-tier lazy storage for libraries up to 10,000+ papers.

### Graph Network & Path Analysis
- **Subfield Boundary Envelopes & Thematic Badges**: The map automatically renders organic boundary hulls enclosing research clusters with auto-labeled thematic topics derived from high-centrality papers.
- **Citation Cascade Animation**: The chronological timeline player animates the network evolution year-by-year, tracing directed citation influence as streaming cascades outward from seminal seed papers to translational applications.
- **"Bridge Paper" & Bottleneck Identification**: Brandes' betweenness centrality algorithm isolates seminal connector papers bridging two distinct disciplines, with one-click map halo highlighting and centrality percentages.
- **Publication-Quality Vector SVG Export**: Export the active cluster or filtered sub-graph as clean vector graphics with inline font styles, marker definitions, and a customizable color legend.

### Systematic Screening Projects (`screening.sqlite3`)
- **Interactive Visual PRISMA 2020 Flowchart**: Real-time SVG rendering of the standard PRISMA 2020 flow (Identification → Duplicates Removed → Screened → Excluded with Reasons → Included) with interactive in-app modal preview and vector download.
- **Active-Learning Queue Sorting**: Embedded client-side Rocchio feedback model continuously surfaces candidate papers most likely to be included as decisions (R/N) are made, maximizing Work Saved over Sampling (WSS@95%).
- **Dual-Reviewer Blind Mode & Reconciliation**: Export anonymized project files for secondary reviewers, paired with an interactive reconciliation dashboard that computes Cohen's $\kappa$ inter-rater reliability and displays discrepancy resolution tables.

### Evidence Matrix & Claim Grounding
- **Section-Targeted Full-Text Harvesting**: Multi-column PDF layout parsing targets explicit section headers (Discussion, Limitations, Methods, Results), achieving >80% fill rates for limitations and study organisms.
- **Consensus & Contradiction Indicators**: Groups findings across shared biological targets/interventions to automatically classify concordant, conflicting, or orthogonal conclusions in table exports.
- **Direct PDF Evidence Navigation**: Clicking supporting citations or comparison-table quotes opens the exact PDF page in the reader.

### Storage & Scalability
- **Two-Tier SQLite Lazy Hydration**: Splits library persistence into lightweight metadata (`papers`) and on-demand content (`papers_content`), reducing initial startup memory heap by ~85% on 5,000–10,000 paper libraries.
- **Single-File `.pulse-workspace` Backups**: Bundle SQLite databases, screening projects, saved searches, and local PDFs into a single portable zip archive with pre-restoration inspection.

### What's New Splash Screen
- An in-app release highlights modal introduces newly updated features upon first launch after an update, and remains accessible at any time from Settings.

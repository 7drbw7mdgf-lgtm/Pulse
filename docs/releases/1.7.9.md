# Pulse 1.7.9 — clearer discovery and reliable paper previews

Citation discovery keeps its successful results when optional extra hops reach the planned eight-second limit. That stop is now an informational notice, rather than a red failed-source card or a false “Partial results” warning. Actual provider failures remain visible; sources that returned papers show that their results were retained.

The preview follows the highlighted paper through sorting and filtering. Checking a result previews that paper. During live collection, the automatic preview follows the leading result until a paper is explicitly chosen. A new search clears the previous preview, and filters with no matching papers clear it too.

- DOI links and citation counts occupy separate lines. Missing or invalid provider counts remain unknown, while explicitly reported zero counts retain their source. Combining metadata keeps counts and provenance together.
- The source-card grid collapses as soon as candidates arrive, leaving a compact status row and search progress. Search details retain the status explanations.
- Graph controls occupy space below the SVG rather than covering nodes. The redundant Library badge is removed, and **Clear papers** moves into the Library **More** menu with its existing confirmation and recovery flow.
- **Open paper** resolves the paper’s DOI, article/full-text URL or supported scholarly identifier. Browser links open a new tab; the desktop app sends them through its existing system-browser navigation handler.

## Verification and package

Regression checks cover expected hop limits versus genuine failures, live and completed source notices, count provenance across providers and merges, preview selection through sorting/filtering and live reranking, compact search progress, safe Library clearing and paper-link activation. A real-browser test checks the updated workspace at 1547×1031 and 1024×720, including opening a paper link.

Local checks passed 224 backend tests (one optional runtime check skipped), 18 frontend suites and the real-browser workspace test. Package checks verified the signature, disk-image checksum, native launch, bundled-source equality, PDF/SQLite support, and offline inference with network access and external runtimes blocked.

The Apple Silicon DMG retains the self-contained offline cross-encoder and macOS 11+ target from 1.7.8. Python 3.10+ for the main backend, Ollama and optional embedding/report models remain separate. The package is ad hoc signed and is not Apple-notarized. The published Windows installer link remains 1.7.6; updated Windows source continues to build in CI. No personal library or credentials are included.

# Pulse 1.8.2 — persistent offline ranker

- **The offline ranker stays running.** The Mac app's cross-encoder is rebuilt with the persistent protocol introduced in 1.8.1, so it loads once (warmed up at launch) instead of starting for every search. In a local test the ranking step for 48 papers took 1.54 s instead of 2.05 s; later searches in the same session save about 0.4 s each.
- **Identical rankings.** The rebuilt ranker gives bit-identical scores to the 1.8.1 ranker (checked on 100 papers, and on 48 papers through the packaged app). It is built with a standalone Python 3.11 targeting macOS 11, verified at build time for single-request and persistent modes.
- **Correction to earlier notes.** Release notes since 1.7.12 described single-passage cross-encoder scoring. The Mac ranker shipped in 1.7.12–1.8.1 was frozen before that setting existed and always scored up to four passages per paper. 1.8.2 keeps the four-passage behaviour explicitly; switching to one passage is faster but changes rankings, so it awaits validation on labelled benchmarks.

## Note on OpenAlex limits
OpenAlex now enforces a daily request allowance for free use. After heavy use, list queries such as citation lookups return HTTP 429 with a long retry time, and Pulse pauses OpenAlex for that period while other sources continue; results can be noticeably thinner until the allowance resets. The live five-seed benchmark was not re-run for this release for that reason; rankings are unchanged by construction.

The Windows installer remains 1.8.0. The Apple Silicon package keeps its macOS 11+ target and PDF support. The main backend requires Python 3.10+. The app is ad hoc signed and not Apple-notarized.

# Pulse 1.7.12 — ribbon map tabs, blank maps, and retrieval performance

- Ribbon map tabs allow managing multiple independent maps within a workspace, including dedicated blank maps (`+ New map`). Each map tab maintains its own active paper nodes and links while sharing the unified workspace library.
- When multiple map tabs are present, library cards (compact cards, expanded cards, and the library table view) display map tab selectors to assign papers to specific maps, all maps, or none. The library bulk action bar includes an "Add to map…" tool to assign multiple selected papers to a chosen map tab in one step.
- Map layout (force, radial, cluster) and SVG graph rendering strictly display the papers and linkages corresponding to the currently active map tab, with responsive empty-state guidance on blank maps. Map tab state and paper memberships persist cleanly across save, export, restore, and workspace recovery.
- Retrieval performance optimizations:
  - Parallelized DBEF pivot searches with OpenAlex field projection (`select=`) to reduce payload overhead and latency.
  - Reusable HTTP connection pooling across repeated OpenAlex and citation discovery requests.
  - Background pre-warming of reference networks and DBEF pivots upon paper selection or addition to the library.
  - Early settling detection in long-tail candidate discovery.
  - Bounded cross-encoder text scoring windows and persistence of cross-encoder embeddings.

## Also first packaged in this installer

These changes were previously available from source only:

- **Concept search:** type a concept or research question into **Find papers** without a seed paper. AI-extracted keywords and synonyms broaden retrieval; the original phrase always remains a query, with phrase-only fallback when AI is unavailable.
- **Calibrated DBEF evidence:** seed-derived saturation replaces batch-max normalisation; assessed overlap, assessed zero and unavailable graph evidence are recorded separately, and missing graph support is imputed conservatively.
- **Co-citation restored** as its own eight-second branch beside direct citations and bibliographic coupling.
- **Research quality:** question-specific relevance feedback, column-aware reference extraction with local OCR for scanned PDFs, stricter DOI verification, and preprint/version grouping with correction and retraction notices.
- **Neural shortlists:** 96 papers for embeddings and 48 single-excerpt cross-encoder scores, with score caching.

## Live timing check

Five seed papers (bacterial outer-membrane vesicles), 200 results, Apple Silicon Mac, packaged backend with external runtimes hidden, one run per seed:

| | 1.7.11 | 1.7.12 |
| --- | --- | --- |
| Time per search | 21.7–30.6 s | **12.5–15.4 s** |
| Collection | 12.7–21.3 s | 6.1–8.0 s |
| Must-find papers in top 50 (of 75) | 13 | 15 |
| Must-find papers in top 200 (of 75) | 51 | 43 |

Must-find papers are each seed’s 10 most-cited citing works and 5 most-cited references (OpenAlex), fixed before testing. Early settling trims some long-tail results. This is a small single-field check with live provider variability, not a general guarantee.

See [reliability details](../search/SEARCH-RELIABILITY.md) and [the ranking benchmark](../search/RANKING-BENCHMARK.md). The Apple Silicon package retains its macOS 11+ target and self-contained offline cross-encoder. The main backend requires Python 3.10+. The app is ad hoc signed and not Apple-notarized.

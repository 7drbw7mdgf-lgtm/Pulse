# Pulse 2.0.1 — Current app, matching Mac and Windows installers

This release packages the 2.0 discovery features for both platforms and removes obsolete copies of the old application from the current repository. Historical release notes, tags and installers remain available.

- **Discovery:** author-trajectory retrieval, relevance feedback that keeps reviewed results in place, available citation contexts and intent, and the bundled scientific cross-encoder.
- **Evidence matrix:** compare selected papers and export Markdown or CSV. Sentences are extracted locally and checked against source abstracts or available full text; these checks do not establish the scientific accuracy of every interpretation.
- **Library:** Trends, cached relationships and graph layouts, background graph workers, retained library rows, lighter autosave and smooth Timeline scrolling.
- **Connections:** optional Semantic Scholar settings and shared Mendeley sign-in. Choose **Use Pulse sign-in** if a computer still has old developer credentials. The shared service was repaired and fresh sign-in and sync were verified on 17 October 2026.
- **Sync and reports:** the encrypted library-sync interface now refers to computers on both platforms. Windows memory monitoring uses its native API. Reports remain local until reviewed and explicitly sent.
- **Repository:** the duplicate legacy app, old helpers, unused screenshots and outdated guides are removed. Security checks now exercise the current backend. Current browser, graph, sync and packaging checks remain.

The Windows installer uses the same frontend and backend as the Mac app. It bundles Python, PDF extraction, English OCR and the portable offline ranker. The Mac app requires Python 3.10+ installed separately and includes PDF dependencies and the offline ranker. Ollama and its optional models are installed separately on either platform.

See [Mac installation](../MACOS-INSTALL.md), [Windows installation](../WINDOWS-INSTALL.md), [performance validation](../PERFORMANCE.md), and [development](../DEVELOPMENT.md). The Mac build targets Apple Silicon and macOS 11+; it is ad hoc signed and not Apple-notarized. The Windows setup targets Windows 10/11 x64 and is unsigned.

# Pulse 1.7.7

12 October 2026

## Discovery fixes

1. **Citation time budget:** Direct one-hop exploration is the default in both UI and backend. Explicit deeper/iterative searches share an eight-second budget for all extra hops, including requests, retries and provider waits. Collected direct and extra-hop results remain available when the budget expires; cancellation still propagates. A shorter enclosing deadline is preserved.
2. **Portable Mac cross-encoder:** The DMG includes a frozen executable, interpreter, CPU ONNX Runtime, NumPy, tokenizer and the pinned MiniLM model. Relative manifest paths survive app relocation. Model-only bundles with an absolute builder-Python path are rejected during staging. The offline ONNX worker retains overlapping abstract/passage windows and pooling. If pairwise ranking is unavailable, the review header reports the fallback.
3. **Visible result bands:** Related uses the top 40% of the final returned list, after folding and diversity ordering, rather than the potentially much larger retrieval pool. Strong match is bounded by the displayed top 10% as well as the full-pool top-10% gate, absolute evidence and at least two independent retrieval channels. Explicit relevance labels override automatic labels. Match metadata is `evidence-v4`; cache keys invalidate previous ranking results.
4. **Foundational papers:** A default prior of at most six points uses known total citations, topic support and a seed-reference/co-citation/shared-reference relationship. It helps select the neural shortlist and final order alongside the existing nine-point relevance-scaled citation-velocity prior. Missing counts, low topic support, popularity without a citation relationship and explicit Not relevant judgements receive no foundational bonus. `foundationalPrior: false` disables this contribution.
5. **CORE resilience:** HTTP 500/502/504 receives one short recovery attempt. Access and rate-limit errors stop immediately. Persistent failures stop further CORE queries; the entire CORE discovery branch is bounded at eight seconds. Partial and other-source results survive. An external service outage remains outside Pulse's control.

## Mac package

`Pulse-1.7.7.dmg` targets Apple Silicon on macOS 11+. The offline ranker includes its own runtime. The main Pulse backend still requires Python 3.10+; PDF dependencies are included. Ollama and model weights for optional meaning search and reports remain separate. The app is ad hoc signed and not Apple-notarized. Personal libraries, credentials, user caches and Ollama weights are excluded.

The latest published Windows installer remains 1.7.6. Updated Windows source runs in CI; this release packages the requested Mac app.

## Verification and limits

Regression checks cover default depth, additional-hop deadline/restoration/cancellation, 700 candidates truncated to 200 results, full-pool and visible Strong gates, capped and relevance-gated foundational support, transient/persistent CORE failures, portable runtime resolution and visible fallback notices. Backend and frontend suites run locally and in GitHub CI. The frozen worker is tested from an empty profile and compared with the existing PyTorch worker. DMG checks run actual offline inference with network and the developer's runtime inaccessible, verify bundled source/version, and launch the native app with a fresh library.

The included synthetic ranking benchmark guards against regressions. It does not measure live provider completeness. The supplied Inciteful landmark comparison has not been repeated against its original seed and labelled paper set; no parity or live latency improvement is claimed from mocked tests.

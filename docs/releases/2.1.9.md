# Pulse 2.1.9

Pulse 2.1.9 delivers major map camera fitting and visibility repairs, clean cluster boundary envelopes, Library Date added tracking, and desktop UI stability enhancements.

### Map visibility & camera fitting
- **Unclipped papers and labels.** Network papers, rendered labels, and topic envelopes reliably stay within the visible canvas above floating map controls and the bottom dock.
- **Degenerate viewport recovery.** Guaranteed protection against zero-dimension camera collapse when switching between full-screen panels (e.g. Bibliography or Settings) and the network graph.
- **Partially clipped camera recovery.** Stored camera views clipped beyond bounds automatically recover to safe viewing coordinates with preserved zoom levels during background analysis and layout steps.
- **Padded collinear envelopes.** Two-paper and collinear topic clusters render with smooth padded envelopes instead of degenerate lines through their nodes.
- **Streamlined envelopes.** Removed redundant floating topic badges from network clusters to keep graph topology crisp and uncluttered.

### Library & workspace
- **Date added column.** Full Library table includes a sortable Date added column with ISO timestamp tracking for newly imported papers, durable reload and duplicate protection, and remembered sort preference.
- **Desktop release dialog dismissal.** The What's New modal layout dynamically adapts to compact desktop screens and preserves dismissal across desktop restarts and local workspace autosaves.

Mac and Windows packages use the same 2.1.9 source and include Python, PDF/OCR tools and the offline search ranker. Existing Pulse installations can use **Settings → App updates**.

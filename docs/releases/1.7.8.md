# Pulse 1.7.8

12 October 2026

## Faster collection and ranking

- **Cross-encoder shortlist:** Up to 75 papers, reduced from 150. Balanced selection still reserves retrieval-channel coverage, and relevance-gated foundational support participates in selection. Overlapping windows continue to cover the title, abstract and available source passages. This bounds work without simply truncating each abstract to its beginning. Candidates outside the neural shortlist remain available under ordinary text/citation ranking; the display limit still supports up to 500.
- **Meaning shortlist:** Up to 150 papers, reduced from 250. The exact research question and seed queries warm immediately. Collection keeps the latest ranked shortlist instead of a backlog of every arriving candidate. Completed background batches are reused by foreground ranking, including batches that complete as collection stops. An inference lock prevents duplicate embedding requests; cancellation and a 12-second foreground budget apply while waiting for it. Optional background warmup has a four-second budget per snapshot.
- **Embedding cache:** SQLite reads and writes use one transaction per batch, and connections close after cache hits. Vectors are keyed by the actual text fingerprint, endpoint and model, so metadata enrichment for the same DOI cannot reuse a stale title-only vector. Existing DOI-only entries are bypassed; the first search after this update may rebuild those vectors. Raw paper text is not stored in the vector cache.
- **Europe PMC:** An eight-second branch deadline matches CORE's cap and bounds transport waits and retries. Shorter enclosing deadlines remain authoritative. Completed papers and partial-source notices are preserved.
- **Timing evidence:** Pipeline API responses include `embeddingSeconds`, `pairwiseSeconds`, `rankingSeconds`, `semanticRankedCount` and `pairwiseRankedCount` alongside collection/total timing. Counts describe papers successfully assessed, not the full retrieved pool.

## Desktop package and verification

`Pulse-1.7.8.dmg` targets Apple Silicon on macOS 11+. The offline cross-encoder includes its interpreter, model and CPU inference libraries. Python 3.10+ for the main backend, Ollama and optional embedding/report models remain separate. The app is ad hoc signed and not Apple-notarized. No personal library, credentials or model cache is packaged. Windows source remains supported and built in CI; the linked published Windows installer remains 1.7.6.

Regression checks cover reduced shortlist sizes, channel coverage, preserved display count, the Europe PMC transport deadline and partial results, warm query/cache reuse across restarts, metadata-enrichment invalidation, in-flight reuse when collection stops and cancellation while waiting for inference. Backend/frontend suites and the existing synthetic ranking benchmark run before release. Native package checks verify version, bundled source, PDF/SQLite support, authenticated APIs and offline inference from the DMG with external runtimes inaccessible.

Synthetic timing inputs compare the 150/75 cross-encoder and 250/150 embedding workloads on the same test Mac. They exclude public provider retrieval and are not a timing guarantee. Reduced neural shortlists trade assessment breadth for latency; retained synthetic ranking metrics do not establish unchanged real-world retrieval quality or Inciteful parity.

### Recorded stress-test timing

The same two synthetic questions and 4,057-character abstracts were used for both versions, with warm models and fresh vector caches. One sample was taken per workload.

| Stage | Previous workload | 1.7.8 workload | Reduction |
| --- | --- | --- | --- |
| CPU cross-encoder | 150 papers · 28.51 s | 75 papers · 14.65 s | 49% |
| Local embeddings | 250 papers · 21.68 s | 150 papers · 12.03 s | 45% |

These are deliberately heavy synthetic inputs, not the user's live seed timings. They exclude source collection and do not include the benefit of embedding warmup during collection. See the [timing record](../../benchmarks/ranking-latency-1.7.8.json). The normal synthetic ranking benchmark retains Recall@50 of 1.0 and nDCG@10 of 0.9872; it does not prove unchanged real-world quality after reducing the neural shortlist. Local verification passed 217 backend tests (one optional runtime check skipped) and 17 frontend suites.

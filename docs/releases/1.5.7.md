# Pulse 1.5.7

## Mendeley

The library connection panel now offers **Export for Mendeley** without requiring developer registration. The RIS file contains only the chosen scope of papers and includes available titles, authors, years, journals, DOIs, abstracts and keywords. Import instructions and the official Mendeley guide appear beside the action.

**Set up direct transfer** opens the connection settings when an application has not been configured. Once connected, the action becomes **Send to Mendeley**. Direct account sign-in still requires registered application credentials; shared application registration and live provider verification remain unfinished. No secret is distributed with this release.

## Graph and library

The static topic legend has been removed from the graph, leaving more room for the paper network.

Click empty graph space to hide the paper inspector and give the map more room. Click a paper node to reopen its details. This automatic hide does not overwrite the saved Inspector preference. Links and area controls remain interactive.

The left library summary and sidebar paper rows use smaller spacing and clearer titles. Long author lists are shortened in the sidebar; full metadata remains in the inspector, full-screen table and hover text.

## Retained features

Full-screen table selection, bulk export/tag/transfer/remove, local undo and workspace recovery remain available, alongside PDF/BibTeX/RIS/JSON import, DOI-first metadata lookup, citation/reference lists, graph discovery, Zotero integration and selected-paper AI reports.

## Verification

All six frontend JavaScript test suites and syntax checks passed. Isolated browser checks used synthetic papers to verify inspector hide/reopen, compact cards, setup access and a downloaded RIS file containing only the chosen paper. Packaged resources, version and app signature were verified. The four existing saved papers and their content were preserved during the localhost update. No live reference-manager transfer or Mendeley account activation was performed.

# Pulse 2.1.11

Pulse 2.1.11 brings significant UX and graphics refinements across the PDF reader, network canvas, and Trends topic dashboard:

### PDF Reader Refinements
- **Reliable Text Highlighting**: Visual highlights and note quotations save instantaneously on local copies without blocking on strict server passage verification.
- **Draggable Comments & Pin Collision Avoidance**: Comment pins and open inline note cards can now be dragged smoothly anywhere on the page to adjust their anchor position. Overlapping comment pins automatically fan out in an elegant circular spread on hover, making clustered notes easy to inspect and grab.
- **Exporting Dragged Annotations**: Moved comments preserve their exact canonical coordinates when exporting edited PDFs, producing standard, compliant PDF sticky notes for Acrobat, Preview, and web viewers.
- **Cleaner Dock Tools**: Removed redundant text markup buttons from the bottom context dock, streamlining access to selection tools and freehand drawing.

### Visual Sharpness & Layout
- **Razor-Sharp Map Resolution**: Applied geometric precision rendering and antialiasing across all SVG nodes, edges, labels, and regions, eliminating blurry downsampling on Retina and high-DPI displays.
- **Working Fit-View & Direct Dock Control**: Graph `fitCanvasToMap` calculates the true padded bounding box across active papers and accounts for bottom dock space, centering all papers with a single click or with `Cmd+0` / `Ctrl+0`. A dedicated `Fit view` shortcut is now located directly in the map tools dock.
- **Reintroduced Trends Topic Map**: Restored the interactive Trends canvas map, 95% confidence share-change indicators, timeline playback, and linked concept groups.

Mac and Windows packages use the same source and include Python, PDF/OCR tools and the offline search ranker. Existing Pulse installations can update via **Settings → App updates**.

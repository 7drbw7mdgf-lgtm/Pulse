# Pulse 1.7.11 — citation verification and progressive discovery

- Author–year citations check the selected paper's retained bibliography before online search. Explicit a/b year suffixes are matched to the actual reference. Long PDF reference tails and provenance survive import, duplicate-paper merging and workspace recovery.
- A chosen citation fetches and validates its DOI record before import. Titles (including Crossref subtitles), named authors and print/online publication dates must agree. Available registry fields fill the citation; failed checks leave the library unchanged, and missing fields are never invented. Exports recheck DOI records that have not passed identity verification while protecting local corrections.
- Rate limits and repeated server/connection faults trigger session-local backoff per credential scope. Cached successes and other sources continue. Search details report provider contributions and retry times; local deadlines/cancellation are excluded from outage counts.
- Large discoveries render in batches of 100, with throttled intermediate ranking. Incoming results and final ranking preserve selected papers, filters, preview position, visible scroll anchors and unchanged rows. Show next appends further batches; bulk actions use the complete available result set.
- The repository includes a reproducible DBEF on/off ranking benchmark with 24 declared known papers, 23 resolved records and three frozen candidate pools. Results are mixed: known-paper hits in the top 20 improve, top-10 nDCG falls slightly, and top-50 recall/landmark coverage are unchanged. Timings, per-paper misses and coverage limits are recorded. No general quality or full-search latency claim is made.

See [reliability details](../search/SEARCH-RELIABILITY.md) and [the ranking benchmark](../search/RANKING-BENCHMARK.md). The Apple Silicon package retains its macOS 11+ target and self-contained offline cross-encoder. The main backend requires Python 3.10+. The app is ad hoc signed and not Apple-notarized. The published Windows installer linked from the README remains 1.7.6; current source continues to build in CI.

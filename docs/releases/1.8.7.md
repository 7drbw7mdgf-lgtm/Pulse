# Pulse 1.8.7 — Mendeley sign-in recovery

- **Recover from an invalid custom application.** In Library connections, choose **Use Pulse sign-in** to replace saved custom Mendeley application settings with the registration shipped with Pulse, then sign in again. Local papers, notes, and sync preferences are preserved.
- **Restart a pending sign-in.** **Restart sign-in** creates a fresh authorization request and cancels the previous attempt. Failed starts remove the old authorization link.
- **Desktop browser handoff.** Mendeley authorization uses Pulse’s native external-navigation handler, avoiding async popup restrictions in WebKit.

Built from the 1.8.6 release source. Automated tests cover shared and custom settings, recovery, callbacks, token exchange and refresh, sync, and local data preservation. The reported failure on the second Mac has not been reproduced directly; these changes address identified recovery and browser handoff gaps.

This is a local build; GitHub publishing is on hold. Apple Silicon only. The app is ad hoc signed and is not Apple-notarized. Python 3.10 or later is required on the receiving Mac.

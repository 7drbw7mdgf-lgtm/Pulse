# Pulse 1.7.3

12 October 2026

## Citation discovery

Forward and backward Semantic Scholar retrieval now have separate OpenAlex fallbacks. Successful reference retrieval cannot suppress a citing-paper fallback after an error or empty response. An OpenAlex reference error also leaves the forward fallback available. OpenAlex recent-paper and `cited_by_count:desc` streams run independently and retain any available results and warnings. Search cancellation and exhausted budgets still stop further requests.

## Ranking and match strength

- A small age-adjusted citation-velocity prior is enabled by default. It compares known citations per publication year within the available field cohort, or the pool when a field cohort is too small. At least three records with usable counts and dates are required. Its contribution is capped at **2.5 points out of 100**, multiplied by topic relevance; unrelated papers receive no bonus. Unknown, invalid or future publication data receives no bonus. `citationVelocityPrior: false` disables it for a request. The optional foundational-paper tilt remains separate.
- **Strong match** requires absolute evidence above its configured threshold, a final rank in the top **10%** of the deduplicated candidate pool, and at least **two independent retrieval channels**. The cutoff rounds up for small pools and is computed before truncating the displayed results. Labels are applied after version folding, bridge ranking, AI triage and diversity ordering.
- Mirrored provider results and variants of the same concept search count as one channel. Distinct citation paths, semantic recommendations, full-text retrieval and network methods can supply independent support. Explicit Relevant / Not relevant judgements stay distinct from automatic match-strength labels. Older cached scores cannot bypass the new gate in the interface.

## Desktop packages

- **Mac:** `Pulse-1.7.3.dmg`, Apple Silicon, macOS 11+. PDF dependencies are included; Python 3.10+ is installed separately. The app is ad hoc signed and not Apple-notarized.
- **Windows:** `Pulse-1.7.3-Windows-x64-Setup.exe`, Windows 10/11 x64. Python and PyMuPDF are bundled. Setup installs for the current user and installs WebView2 if needed. The initial Windows installer is unsigned.

Ollama and model weights remain separate on both platforms. No personal library, credentials or model weights are packaged. Mendeley shared sign-in still requires owner registration and hosting; RIS export remains available.

## Verification

Targeted regression checks cover asymmetric provider failures, the established-stream fallback, cancellation, citation-prior limits and opt-out, missing metadata, full-pool decile boundaries, provider mirrors, diversity order and interface label safeguards. The complete backend and frontend suites run in GitHub CI. Windows packaging installs and launches the setup in an isolated profile and checks the bundled PDF/DOI reader, full-text passages, library persistence, session authentication and backend cleanup. Mac packaging verifies the native app and DMG integrity.

Synthetic and mocked checks establish the tested behavior; they do not measure live discovery completeness or AI report accuracy.

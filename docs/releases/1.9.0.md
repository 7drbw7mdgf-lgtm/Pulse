# Pulse 1.9.0 — Encrypted sync between your Macs, and problem reports you control

## Sync between your Macs (Settings → Sync & privacy)
- **Turn on sync** on one Mac and enter the code it shows on your other Macs (**Use a code from another Mac**). Pulse then keeps the library, notes, tags, reading status, relevance and map membership the same on each Mac. It syncs every minute while Pulse is open, when the window regains focus, and on **Sync now**.
- **End-to-end encrypted.** Your sync code (32 random bytes) never leaves your Macs. The encryption keys are made from it, and the relay only stores data it cannot read. Keep the code private, like a password.
- **Merges by paper and by field.** Edits made to different fields on two Macs both survive, and tags and other lists merge. If the same note is edited on both Macs, both texts are kept, marked "From your other Mac". The same paper already present on both Macs is matched (by DOI or title), not duplicated.
- **Deletions are safe.** A paper removed on one Mac is removed on the others through Pulse's normal removal, so **Recovery** can restore it. If a paper was edited on another Mac after it was removed, the edit wins and the paper stays.
- **What stays on each Mac:** PDFs, extracted full text, map positions and citation-metric caches.
- **Turn off on this Mac** stops syncing and keeps the local library. **Turn off and erase the cloud copy** also deletes the encrypted copy from the relay.

## Problem reports (Settings → Sync & privacy)
- When something goes wrong (an app error, a backend error, or the Pulse background process using more than 3 GB of memory), Pulse records a report **on this Mac only**. The report keeps the error type, code locations, app and macOS versions, uptime and memory use.
- Before anything is saved, paper titles, notes, search text, DOIs, keys, tokens, e-mail addresses and home-folder paths are removed.
- After a problem, a small notice offers **View report**. Pulse sends a report only when you click **Send report**, and the window shows exactly what will be sent. The same fault repeating is counted rather than stored many times. Reports can be deleted at any time.

## Also fixed
- Settings no longer shows the Mendeley & Zotero section twice (a 1.8.9 merge artefact). A test now rejects duplicate element IDs.

Both features use Pulse's relay, a Cloudflare Worker with a D1 database on the free plan (`services/relay`). Tested with two separate profiles syncing through the live relay: joining with an existing library, merged notes, edits on each side, a removal, and restarts. Both libraries ended up identical. A problem report was recorded, viewed and sent. Test data was erased afterwards.

The Windows installer remains 1.8.0. The Mac app needs Apple Silicon, macOS 11+ and Python 3.10+. It is ad hoc signed and not Apple-notarized.

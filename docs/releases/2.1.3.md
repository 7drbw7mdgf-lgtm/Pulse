# Pulse 2.1.3

Search within the active network by keyword, tag, author, note or quoted phrase. Any-word and all-word matching highlight the matching papers and links between them, while keeping graph positions and relationship calculations unchanged.

The discovery ribbon and options panel use a more compact layout, with citation depth shown when Citations is enabled and advanced options grouped together. Map controls have labelled Pan/Select buttons, readable paper/link counts and a Tools menu for labels, spacing, style, areas, link details and the paper assistant. The toolbar follows the selected theme and adapts to the available space. Theme selection lives in Settings.

Settings now uses a searchable Pulse Options layout with a category sidebar, grouped controls and Apply/Close actions. Choose System, Light, Dark, Sepia or High Contrast; appearance persists across app launches.

Research workflows add local PDF and open-access full-text evidence with source passages, citation verification, screening projects, tags, memos, undo and RIS/CSV/PRISMA working-data exports. Search shows individual source status and supports targeted retries. Disk cache maintenance bounds storage while preferring reusable work metadata.

Adaptive citation weighting and biomedical reranking remain opt-in because benchmark results varied by dataset. The optional biomedical model is installed separately. The standard offline MiniLM ranker, Python and PDF/OCR tools are included.

The earlier local Mac package uses an ad hoc signature and is not Apple-notarized. The latest UI changes are included in source; installers must be rebuilt from this commit to include them. In-app updates remain enabled for signed releases published to GitHub.

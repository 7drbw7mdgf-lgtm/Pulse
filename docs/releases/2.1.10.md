# Pulse 2.1.10

Pulse 2.1.10 restores the clean, responsive frontend UI and network graph layout from version 2.1.6 while preserving all backend performance enhancements, preprint server discovery, PDF table extraction, and evidence synthesis capabilities.

### Frontend UI Restoration
- **Original 2.1.6 Interface**: Restored the clean frontend layout, full-canvas graph rendering, navigation dock, and inspector styling from v2.1.6.
- **Fixed Script Loading**: Resolved script redeclaration errors by unifying the client application structure.
- **Topology & Canvas**: Clean node-link graph visualization with dynamic edge styling for citations, bibliographic coupling, and semantic similarity.

### Core Capabilities Preserved
- **Preprint Server Support**: Direct search and ingestion across arXiv, bioRxiv, and medRxiv.
- **PDF Extraction**: Structured scientific table extraction and full-text parsing.
- **Workspace Archives**: Complete export and import of literature maps and workspaces.
- **Evidence Matrix**: Synthesis extraction and citation provenance.

Mac and Windows packages use the same source and include Python, PDF/OCR tools and the offline search ranker. Existing Pulse installations can use **Settings → App updates**.

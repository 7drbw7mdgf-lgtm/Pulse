# Pulse 1.7.2

12 October 2026

Local Mac installer: **Pulse-1.7.2.dmg** (Apple Silicon, ad hoc signed).

## Discovery and evidence

- Multi-seed bridge discovery accepts 2–8 distinct seeds, searches their combined concepts and explains evidence for each connection. Adding a bridge creates links to the supported seeds.
- PMC passage retrieval checks article identifiers and retains section names, source, permissions and coverage. Missing full text preserves the abstract.
- S2ORC JSONL/JSONL.GZ imports create a local passage index. Full-text library search can find body evidence absent from paper titles. Corpus metadata is joined by exact identifiers; passages remain separate from abstracts.
- Phrase-aware concept queries, a larger balanced retrieval pool, cooperative provider budgets and streaming partial results improve discovery robustness. Relevant/Not relevant feedback applies only to the same question and seeds.
- Pool-independent match evidence and optional locally validated thresholds replace relative-score-only categories. Published SciFact benchmark reports and reproducible evaluation tools are included in source.

## Local AI

Model roles are configurable: `nomic-embed-text` for embeddings, `llama3.2:3b` for optional shortlist relevance review and `qwen2.5:7b` for selected-paper reports. Relevance review keeps uncertain results available and does not override user labels. Reports use only the selected paper and clearly identify a selected passage set.

Python 3.10+ and Ollama are installed separately. Model weights are not included in the DMG. The optional isolated cross-encoder runtime is a separate source setup; text/citation ranking continues when it is unavailable. S2ORC content requires a local corpus import.

## Validation

174 backend tests and 17 current-workspace JavaScript suites passed for this source revision. Live checks verified open-access PMC passage retrieval and inference with all three local model roles. The 30-question offline SciFact evaluation is described in `benchmarks/README.md`; its measurements do not establish live provider coverage or general scientific accuracy.

Packaging verifies application version, bundled source, ad hoc signature and DMG integrity. No personal library, credentials or model weights are included. The application is not notarized by Apple. Mendeley shared sign-in still requires owner registration and hosting; RIS export remains available.

# Pulse 2.1.12

Pulse 2.1.12 improves Mendeley connection recovery, exact paper lookup, and library navigation. Mac and Windows use the same frontend and backend source.

- **Mendeley recovery:** disconnected legacy Pulse application settings now use the shared sign-in service. Reconnecting also clears stale legacy tokens. Working sessions and explicitly saved custom applications are preserved. No application secret is bundled.
- **DOI and article-link search:** paste a DOI, DOI URL, PubMed URL, or public article-page link into the search bar and press Enter. Results use identifier or article metadata lookup and can be added explicitly. My library searches saved DOI/link fields locally. Exact lookup results stay visible when already in the library.
- **Bibliography:** selecting a paper opens the right inspector while keeping the table in view. The On map checkbox column is removed, the Map selector is narrower, and Date added is sortable at the right. New imports record their added time; older records without that information remain unknown.
- **Simpler Trends:** topics and matching papers are shown side by side, with a period selector and optional map, timeline, keyword filters and detailed statistics.
- **Compact search controls:** scope, matching, ranking, tags and saved searches are grouped in an options pill. Bibliography filters take less space.
- **Download links:** the project README links to the current installers and latest release.

Python, PDF extraction, OCR and the offline search ranker remain bundled. Optional Ollama and model weights remain separate. Existing Pulse installations can update through **Settings → App updates**; the library and connection settings stay in the separate user profile.

## Validation

Mendeley callback, refresh, sync and legacy-registration recovery tests; DOI/article lookup tests including already-saved papers and persisted local filters; topic search, saved search and Bibliography browser regressions. The shared Mendeley credentials, a fresh account sign-in and library sync were also checked on 26 October 2026. Native package checks are required before this release is published.

# Pulse 1.8.0 — discovery quality, direct-citation influence, persistent HTTP cache and arXiv

- **Direct-Citation Influence Bonus**:
  - Elevates landmark direct-citation neighbours using citation velocity ($P(\text{velocity})$) gated by topic similarity ($\text{gate}(\text{topic})$), increasing top-20 discovery recall by over 3× on benchmark seeds without drifting off-topic.
  - Bonus is factored into preliminary candidate scoring for neural shortlists so high-velocity direct citations reach the cross-encoder for pairwise verification.
  - Explainable scoring: recorded in `scoreBreakdown.citationLinkBonus` with user-facing insight: *"Directly linked to your seed and widely cited"*.
- **Search Speed and Persistent HTTP Cache**:
  - Over 3× faster warm search times (reducing 200-result searches from ~14 s to ~4 s).
  - Persistent SQLite HTTP cache (`http-cache.sqlite3`, 200 MB LRU, credentials excluded) with 24-hour TTL for works and citation graphs, 15-minute TTL for keyword searches.
  - Automatic `Accept-Encoding: gzip` compression and streaming decompression across all external provider requests.
  - OpenAlex `select=` field projection across citation graph, co-citation, paper metrics, metadata resolution, and reference lookup queries to eliminate unnecessary network transfer.
- **Keyless Public Literature Search**:
  - Integrated public arXiv search alongside Europe PMC and OpenAlex for instant, keyless discovery out-of-the-box.
  - Default search sources set to zero-configuration public APIs (`europePmc: true, arxiv: true, openalex: true`).

See [citation bonus details](../search/CITATION-LINK-BONUS.md) and [the ranking benchmark](../search/RANKING-BENCHMARK.md). The Apple Silicon package retains its macOS 11+ target and self-contained offline cross-encoder. The main backend requires Python 3.10+. The app is ad hoc signed and not Apple-notarized.

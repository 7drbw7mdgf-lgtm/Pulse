# Pulse 2.1.13

Pulse 2.1.13 hardens cross-device sync consistency, local desktop session security, and workspace archive restoration while consolidating the frontend stylesheet architecture:

### Security & Data Integrity
- **Atomic Sync Relay Conflict Guards**: Guarded Cloudflare D1 record upserts against concurrent vault head changes so racing pushes return HTTP `409` cleanly without committing stale sequence numbers or overwriting concurrent updates.
- **One-Time Desktop Bootstrap Session**: Consumes `BOOTSTRAP_CONSUMED` immediately upon authenticated Tauri startup and when `PULSE_LAUNCH_FILE` is used, preventing unauthenticated local requests from receiving session tokens.
- **Synchronized & Bounded Workspace Archive Restore**: Acquires `LIBRARY_WRITE_LOCK` across archive export and restore, enforces uncompressed entry size limits, rejects path traversal, verifies SQLite (`SQLite format 3\0`) and PDF (`%PDF-`) headers with `PRAGMA quick_check(1)` before atomic replacement, and preserves two-tier `papers_content` full text and OCR during merge restores.
- **Explicit Cipher Tagging for Stored Secrets**: Added `cryptography` to backend requirements and tagged AES-GCM vs. HMAC-SHA256 fallback payloads in `enc:v1:` secrets while retaining legacy secret compatibility.

### Frontend & Repository Hygiene
- **Consolidated Stylesheet & Domain Architecture**: Merged fragmented CSS parts (`part_01.css`–`part_18.css`) into `css/core-ui.css`, unified stylesheet imports in `style.css`, and added `window.PulseDomainManifest` for explicit frontend domain ownership.
- **Working-Tree Cleanup**: Removed the untracked 19.1 MB `benchmarks/headtohead-frozen-pool.json` fixture from the repository working tree in accordance with `CITATION-STRUCTURE.md`.

Mac and Windows packages use the same source and include Python, PDF/OCR tools and the offline search ranker. Existing Pulse installations can update via **Settings → App updates**.

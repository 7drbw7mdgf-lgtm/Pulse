# Pulse 2.1.0 — Faster libraries and reusable searches

- Multi-phrase search: separate phrases with commas or semicolons, quote exact phrases, and select **All terms** or **Any term**. Add `#tags` or choose library tags. **Online papers** uses tags as keyword phrases; **My library** matches the tags saved on your papers. Natural-language questions remain supported.
- **Fast** ranking uses text and citation evidence without model reranking or AI keyword expansion. **Enhanced** ranking adds the configured semantic and bundled pairwise models. Enhanced results are not guaranteed to be more relevant in every discipline.
- Save searches with their keywords, tags, sources and ranking mode. Mark one as a watchlist and click **Check new** to find matches not seen in previous checks. The first check establishes the baseline. Checks run only when requested. Removed saved searches can be restored.
- Use **To read** above the library to open the reading queue. A selected Trends concept can be loaded into search and saved as a watchlist.
- Selection no longer rescans every relationship for every map node. Relationship indexes serve counts, strongest links, neighbours and active-map views. Graph calculation caches document tokenization and unaffected vectors, uses exact sparse candidate bounds, and indexes shared references and citing papers. Citation evidence and qualifying similarity links are retained.
- The citation library now uses transactional SQLite storage and per-paper updates with indexed phrase/tag search. Existing JSON libraries migrate automatically while preserving their original JSON and a separate migration checkpoint. Notes, full text, tags, map assignments, sync IDs and unknown workspace fields survive migration. JSON export and existing Recovery actions remain available. Periodic JSON checkpoints supplement database transactions.
- **Settings → Connections → Check connections** checks the library database, Mendeley profile access and a configured Semantic Scholar key, with distinct recovery advice for expired sign-in, application credentials, rate limits and response formats. The check does not send your library.
- The Mac package now includes its Python backend, PDF/OCR dependencies, trusted CA certificates and offline ranker. Users no longer install Python separately. Optional Ollama and its model weights remain separate.
- Release scripts support Apple signing/notarization and Windows Authenticode signing when publisher certificates are configured. Development installers remain ad hoc signed on Mac and unsigned on Windows until those credentials are supplied. See [signing setup](../SIGNING.md).

The 2.0.2 Bibliography view, manual-tag filtering and map-tab fixes are retained. These changes are prepared locally; this note does not claim a GitHub release has been published.

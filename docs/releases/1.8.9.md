# Pulse 1.8.9 — Faster libraries and cached Trends

- Relationship analysis and settled map positions are reused until relevant inputs change. Larger libraries calculate relationships and force layouts in a background worker; stale results cannot replace newer edits, maps or pinned positions. A fallback remains available if workers cannot start.
- The Library retains unchanged cards and table rows, mounts a small scrolling window, and keeps focused editors intact. Filtering, sorting, map assignment and bulk actions still operate on all matching papers.
- Autosave skips unchanged snapshots and combines pending edits. After an acknowledged baseline, small updates transfer only changed papers and workspace fields. A conflicting saved baseline is kept locally and requires reloading or Recovery before remote saves resume. Disk checkpoints remain complete, atomic JSON files with recovery backups.
- Trends opens a cached dashboard of the whole saved library: publication activity, concepts, existing topic groups and clickable paper lists. Selecting or moving a paper does not rebuild the aggregates.
- Dense maps draw a bounded selection of their strongest links and show the drawn/total count. All relationship evidence remains available in state, linkages and exports.

Semantic Scholar settings and the five-card Timeline remain included.

**Also in this release (merged from 1.8.4–1.8.6):** faster first search results and pre-warm on selection, OpenAlex fallbacks and optional key, Clear map with Undo, drag-to-map with focus, quiet duplicate-safe Mendeley sync, and one-click Mendeley sign-in through Pulse's sign-in service.

**Mendeley sign-in:** the sign-in service's application secret was replaced on 17 October after Mendeley rejected the previous one. Errors now name the failing step. Mendeley answers HTTP 401 both for an expired or already-used sign-in and for wrong application credentials, so Pulse asks you to connect again first; if 401 keeps recurring, the service's application secret needs updating (see [Mendeley registration](../MENDELEY-ACTIVATION.md)). RIS export is always available.

See [performance validation](../PERFORMANCE.md) and [Mac installation](../MACOS-INSTALL.md). The Mac build supports Apple Silicon, macOS 11+, and Python 3.10+. It is ad hoc signed and is not Apple-notarized.

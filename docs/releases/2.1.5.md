# Pulse 2.1.5

Open-access PDFs now load inside Pulse through verified public repository files, including the current NCBI Cloud dataset. Pulse checks article identity and renders accessible PDFs with its bundled engine. An online copy opens as a read-only preview with its source shown. **Download & annotate** retains a local copy for editing and offline reading.

The PDF workspace includes Read, Comment, Edit and Pages tabs, page thumbnails, document search, highlights, underline, strikethrough, comments, text boxes, pen drawings and rectangles. Rotate, reorder or exclude pages, undo/redo edits, and export a separate edited PDF. Original files and page-linked quotations remain intact. Text boxes add content; existing paragraph reflow, PDF form editing and signature editing are not included.

Map controls are more compact and sit inside the map, with Library first in the bottom navigation. Paper/link totals sit at the top right. Long paper details wrap and scroll vertically. The map’s paper-details panel and the PDF reader’s properties panel start closed, with controls to reopen them.

Mac and Windows packages use the same 2.1.5 source and include Python, PDF/OCR tools and the offline search ranker. Optional local AI components remain separate. Existing Pulse 2.1.2 or later installations can use **Settings → App updates**; setup wizards and regular installers are available for first installation.

Update packages carry signatures verified by Pulse. The Mac app remains ad hoc signed and is not Apple-notarized; the Windows installer has no publisher certificate.

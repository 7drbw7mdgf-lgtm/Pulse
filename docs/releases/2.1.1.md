# Pulse 2.1.1 — Citation collection and ranking

- Rank observed shared references and co-citation alongside text. Common references receive less weight, co-citation is normalized by citation degree, and the structural contribution remains available after neural reranking. The extra structural contribution is bounded to six score points. Topical backward references receive a separate bounded adjustment.
- Author history is topic-gated and receives a reduced vote when it has no corroborating citation route. First- and senior-author history for the same seed count as one retrieval channel. Author labels and candidates remain available.
- Download the full indexed outgoing reference-ID list in parallel batches, independent of the displayed result limit. Preserve reference IDs beyond the former 160-ID metadata cap. Missing metadata and provider limits remain visible as partial coverage.
- Graph and co-citation collection share the same bounded incoming neighborhood, expanded from the former 16-citer co-citation sample. Citing lists remain samples for highly cited seeds; this does not claim exhaustive co-citation coverage.
- Reuse public OpenAlex work metadata across singleton, DOI, search and batch responses. Cached partial records cannot stand in for missing reference fields. Correct seven-day caching for URL-encoded citation queries. No API keys, email query parameters or personal library notes are stored in this cache.
- Run seed resolution alongside topic providers, preserve cancellation/deadlines/request budgets in nested requests, and publish either citation direction as soon as it arrives.

One live public-seed check fetched all 78 indexed references and 79 citing results in 1.334 seconds cold (four OpenAlex requests), then 0.065 seconds warm (zero requests). These are citation-neighborhood timings, not end-to-end search timings or a Mac-to-Mac performance guarantee.

Relevance results on the fixed 146-case pools are mixed. The new policy increases SYNERGY Recall@50 and slightly changes the other measures, while RELISH Recall@50 declines and the five-seed head-to-head set has one fewer known paper in its top 50. This build does not establish a relevance win over Inciteful. See [evaluation details](../search/CITATION-STRUCTURE.md).

The existing 2.1 performance, search, SQLite and bundled-runtime changes remain included. This release is prepared locally; public signing certificates and native Windows verification remain pending. No GitHub release is implied by this note.

# Pulse 1.7.5

12 October 2026

## Citation retrieval resilience

- **Forward citations first:** Discovery citation searches now query forward citations (papers that cite the seed) before backward references, across both Semantic Scholar and OpenAlex fallbacks. Landmark papers citing the seed arrive within the first few requests, preventing retrieval drops if subsequent searches reach transport limits.
- **Batched OpenAlex references:** Seed references are now fetched in batches of up to 100 works per request using OpenAlex's `filter=cited_by:{seed}` (sorted by citation count descending) and multi-work ID batches (`filter=openalex_id:...`), replacing dozens of sequential requests with 1–2 batched queries.
- **Increased request headroom:** Parallel branch request budget increased from 24 to 48 concurrent requests, providing headroom for Europe PMC, CORE, and citation traversals.
- **Co-citation branch batching:** Co-citation candidate lookups now batch top co-cited work IDs in a single query rather than individual lookups.

## Paper access & external links

- **Unified paper URL resolver:** Introduced `paperOpenUrl` to reliably normalize DOI identifiers (stripping redundant `https://doi.org/` or `doi:` prefixes) and fall back cleanly to direct URLs (`url`, `landingPageUrl`, `fullTextUrl`, `pdfUrl`) before falling back to search queries.
- **Direct browser opening:** Opening papers from the Inspector, Timeline, Discovery Preview, and Library Table correctly dispatches clean URLs to the system default browser via native desktop openers on macOS and Windows.

## Desktop packages

- **Mac:** `Pulse-1.7.5.dmg`, Apple Silicon, macOS 11+. PDF dependencies are included; Python 3.10+ is installed separately. The app is ad hoc signed.
- **Windows:** `Pulse-1.7.5-Windows-x64-Setup.exe`, Windows 10/11 x64. Python and PyMuPDF are bundled.

# Pulse 1.8.8 — Search settings and smoother Timeline

- **Semantic Scholar API key in Settings.** Open Settings → Search sources → Semantic Scholar, enter an optional API key, and save it. Keys are encrypted locally; status shows whether a saved or environment key is in use. Search, metadata, citations and recommendations use the key. A saved key can be removed without exposing it.
- **Smoother Timeline scrolling.** Only five nearby paper cards are mounted, even with a thousand papers. Scrolling preserves the native scroll surface and nearby cards, coalesces work per frame, and updates the inspector after scrolling settles. Year and keyboard navigation stay immediate.
- **Mendeley errors identify the failing stage.** The token service preserves application credential failures, and Pulse distinguishes those from account verification errors. Repeated browser sign-in does not repair an application ID or secret rejected by Mendeley. The shared service’s credentials require owner correction; the app installer cannot replace that server credential.

Built from the latest local 1.8.7 source. No GitHub push or release publication. The Mac installer is for Apple Silicon, ad hoc signed, and not Apple-notarized. Python 3.10 or later is required.

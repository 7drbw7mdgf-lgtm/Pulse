# Pulse 1.8.8 — Search settings and smoother Timeline

- **Semantic Scholar API key in Settings.** Open Settings → Search sources → Semantic Scholar, enter an optional API key, and choose **Save**. Keys are encrypted locally; status shows whether a saved or environment key is in use. An environment key takes precedence. Search, metadata, citations and recommendations use the effective key. **Remove saved key** removes the locally saved key. Public search remains available without a key.
- **Smoother Timeline scrolling.** Only five nearby paper cards are mounted, even with a thousand papers. Scrolling preserves the native scroll surface and nearby cards, coalesces work per frame, and updates the inspector after scrolling settles. Year and keyboard navigation stay immediate.
- **Mendeley errors identify the failing stage.** The token service preserves application credential failures, and Pulse distinguishes those from account verification errors. Shared sign-in and sync remain blocked while Mendeley rejects the service's application credentials. The Pulse owner must correct the service's application ID or secret; reinstalling the app or repeating browser sign-in does not repair that server setting. Mendeley RIS export remains available.

The Mac installer is for **Apple Silicon**, requires **macOS 11 or later** and **Python 3.10 or later**, and is **ad hoc signed**, not Apple-notarized. Updating the app preserves the library in your user profile. See the [Mac installation instructions](../MACOS-INSTALL.md).

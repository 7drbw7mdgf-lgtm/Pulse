# Pulse 1.5.8

8 October 2026

- Automatically look up details for imported and restored papers, using DOI first and conservative bibliographic matching when no DOI is available.
- Check metadata before selected-paper, bulk, map, table and citation-list exports. Carry available date, volume, issue, page range or article number, publisher, identifiers, language, URL and keywords into exports and reference-manager sends.
- Preserve local metadata corrections across repeated lookup. Missing registry data remains blank and ambiguous matches retain the original details.
- Add a deployable shared Mendeley sign-in service. Provider secrets and tokens stay on the server; the Mac receives a protected per-device session. Ordinary users' developer settings are hidden.
- Add automatic and manual Mendeley library import, complete pagination, account-bound matching, local-edit protection, remembered removals and clear-workspace pause.
- Serialize saves and guard delayed autosaves from overwriting removal or recovery operations.

The default installer has **no activated Mendeley service**. RIS export works now; direct sign-in and sync require one owner registration and HTTPS deployment. See [activation](../MENDELEY-ACTIVATION.md). Real Mendeley authentication has not been tested; local verification uses simulated accounts. Python, Ollama and local model weights remain separate installations. The Mac build is ad hoc signed and is not notarized.

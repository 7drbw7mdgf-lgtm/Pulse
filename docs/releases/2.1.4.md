# Pulse 2.1.4

The network has a Focus map button and resizable Library and paper-detail panels. Network search now supports previous/next match, Fit all matches, Show matches only and excerpts showing where keywords matched. Select two papers to inspect a connecting path, with citations, shared references, co-citation and similarity clearly distinguished.

Smart collections keep Library groups up to date using keywords, tags, reading status and publication years. Duplicate review compares suspected pairs side by side, lets you choose metadata, preserves notes, tags, attachments and map membership, and creates a durable recovery point for Undo.

Read local PDFs inside Pulse, highlight text, add memos and send page-linked quotations to Notes or the Evidence Matrix. Quotations are checked against the local page. Scanned pages use bundled English OCR when available. Older PDF imports need the original file attached once; PDF binaries and annotations stay local.

Saved watchlists can check daily or weekly while Pulse is running. New candidates go to a New papers inbox for review, with deduplication, provider status and retry handling. Manual checking remains the default.

This release also includes the previously unpublished 2.1.3 changes: compact discovery and map controls, keyword highlighting on the network, searchable Word-style settings with five themes, full-text evidence and citation verification, formal screening projects, source retries and bounded disk-cache maintenance. Adaptive citation weighting and biomedical reranking remain opt-in because benchmark results varied by dataset.

Mac and Windows installers use the same source. Python, PDF/OCR tools and the offline MiniLM ranker are bundled. Optional local AI and biomedical model downloads remain separate. The setup wizards and signed in-app update feeds both install 2.1.4; existing Pulse 2.1.2 or later users can use Settings → App updates.

Update packages carry cryptographic signatures verified by Pulse. The Mac app remains ad hoc signed and is not Apple-notarized; the Windows installer has no publisher certificate.

See [workspace tools](../WORKSPACE-TOOLS.md) for usage, PDF portability, merge recovery and watchlist scheduling details.

# Pulse 1.7.1

11 October 2026

Mac installer: [Pulse-1.7.1.dmg](https://github.com/7drbw7mdgf-lgtm/Pulse/releases/download/v1.7.1/Pulse-1.7.1.dmg) (Apple Silicon, ad hoc signed).

This release completes the discovery review workspace and includes the tabbed paper inspector and private reading notes developed for 1.7.0. It supersedes the published 1.6.0 installer.

## Review discovery results in one workspace

- Three columns keep review queues and filters, grouped paper rows, and the selected paper's preview together.
- Strong matches, Related and Worth exploring organize candidates. To review, Relevant, Not relevant, Already in library and All results track your decisions.
- Match explanations name shared authors, citation relationships and matching topics when available. Search-only results retain that distinction. Relative scores are not relevance probabilities.
- Source progress remains visible while searches run. Stop and review keeps results from finished sources; stopped or failed searches are marked as partial. Rate-limit guidance only offers an API-key setting for sources that support it.
- Individual and group selections drive the bulk count and library/map additions, relevance labels and RIS export. Filtered selections remain explicit.
- J/K moves through visible papers, R/N marks relevance, A adds the focused paper and Space toggles its selection.
- Reset filters now clears reason and match-strength facets as well as the original filters.
- HTML is stripped from provider titles. An unavailable zero count cannot replace a known citation count from another source.

## Paper inspector and notes

- A fixed header provides library previous/next navigation, compact bibliographic identity, DOI and reading-status chips, primary actions and a maintenance menu.
- Overview places the abstract, citation metrics, local-AI findings and concepts together.
- Connections shows links to other library papers, citing papers and references.
- Notes stores reading status, relevance, personal tags and private notes with the local library and JSON exports. These fields are not sent to search services or reference managers.
- Light and dark themes, the full-screen library table, bulk actions, recovery and the stacked timeline remain available.

The README now includes current 1.7.1 screenshots from an isolated synthetic library. Its example records, search results and source warning are simulated; no personal reading list is published.

## Verification and requirements

136 backend tests, 23 root Python tests, 16 current-workspace JavaScript suites, graph unit checks and loopback security checks passed. Browser verification covered completed and stopped searches, partial-source warnings, reason/strength reset, selection counts, relevance queues, adding a paper, note persistence, paper navigation and both themes. The historical browser/performance suites and separate shared sign-in tests were not rerun for this release.

The DMG's integrity, application signature, version metadata and packaged source are verified during release preparation. Checks use synthetic or mocked data; they do not establish live retrieval recall or AI-report accuracy.

Apple Silicon, macOS 11 or later, and Python 3.10 or later are required. PDF dependencies are included; Python, Ollama and model weights are separate installations. The app is ad hoc signed and is not notarized. Mendeley RIS export works; the shared sign-in service still needs owner registration and hosting before public activation.

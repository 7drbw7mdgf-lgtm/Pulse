# Pulse 1.7.4

12 October 2026

## Ranking and match strength

- **Relevance-scaled citation velocity prior:** The default age-adjusted citation-velocity prior now contributes up to **9 score points out of 100** (scaled by `.09 * impact * topic_support`). The bonus requires topic support and citation velocity within the candidate cohort; papers with no topic relevance receive zero prior bonus. Invalid or missing publication metadata remains neutral, and `citationVelocityPrior: false` provides a per-request opt-out.
- **Pool-relative Related band:** Automatic **Related** results now occupy the top **40%** of the final deduplicated candidate pool after sorting and diversity selection, prior to applying the display limit.
- **Explore band:** Covers the remaining candidates outside the top 40% band.
- **Strong match safeguards preserved:** Retains its strict triage criteria: absolute evidence above the configured threshold, pool rank in the top 10% (`pool_rank <= ceil(pool_size / 10)`), and verification across at least **two independent retrieval channels**. Strong matches are contained within the top-40% review band. Explicit user relevance judgements (Relevant / Not relevant) remain distinct and take precedence.
- **Metadata versioning:** Match-strength metadata now uses `evidence-v3` to distinguish the pool-relative classification rules.

## Windows reliability

- **Backend readiness retry:** Retries readiness-file cleanup while the backend writer closes, preventing first-launch file lock collisions.
- **Smoke test isolation:** Isolates Windows WebView smoke checks and captures native startup diagnostics.

## Desktop packages

- **Mac:** `Pulse-1.7.4.dmg`, Apple Silicon, macOS 11+. PDF dependencies are included; Python 3.10+ is installed separately. The app is ad hoc signed and not Apple-notarized.
- **Windows:** `Pulse-1.7.4-Windows-x64-Setup.exe`, Windows 10/11 x64. Python and PyMuPDF are bundled. Setup installs for the current user and installs WebView2 if needed. The Windows installer is unsigned.

Ollama and model weights remain separate on both platforms. No personal library, credentials or model weights are packaged. Mendeley shared sign-in still requires owner registration and hosting; RIS export remains available.

## Verification

Targeted regression tests verify the 9-point scaled velocity prior, pool-relative Related cutoffs, top-decile multi-channel Strong match constraints, and Windows lifecycle handling. All backend and frontend test suites pass in CI, and native packaging builds verify bundle integrity and checksums.

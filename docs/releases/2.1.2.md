# Pulse 2.1.2

Pulse can now download and install updates from inside the app. Settings → App updates checks GitHub, shows progress, supports cancellation and offers Restart & update after signature verification. Automatic downloading can be turned off. Pulse saves the library before restarting and preserves its profile, connection settings and local models.

A lightweight native setup wizard handles first installation and optional local AI components on Mac and Windows. Python, PDF tools, OCR and the offline ranker are included in the app; no development tools are needed.

This release also includes the unpublished 2.1 changes: multi-keyword/tag search, Fast/Enhanced search, saved searches and watchlists, a reading queue, faster graph calculations, incremental SQLite library saves, full indexed references, citation-structure ranking and OpenAlex caching. Citation benchmark results were mixed across datasets; see the detailed [citation evaluation](../search/CITATION-STRUCTURE.md).

Install 2.1.2 once to enable in-app updates. Earlier versions do not have an updater. Update signatures are included; Apple notarization and Windows publisher signing still await publisher certificates.

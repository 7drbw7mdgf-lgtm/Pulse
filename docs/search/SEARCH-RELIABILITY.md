# Citation and search reliability

The development source adds [evidence-weighted DBEF, contrastive feedback, local OCR, publication notices and a 40-question review benchmark](QUALITY-UPGRADE.md). It limits costly neural scoring to 96 embedding candidates and 48 query-focused pairwise candidates, preserving the full result pool and complete stored paper text. Benchmark proposals are explicitly separated from human judgments; no held-out DBEF fit is activated without sufficient reviewed seeded cases.

Concept search accepts a topic through the Find papers input and Search papers button, without a seed paper. The same discovery job API accepts `searchMode: "concept"` and `query`; validation happens before a background job is started. The concept path does not fabricate a seed or run citation/DBEF/recommendation lookups for one. It sends only the typed topic to the configured AI for a bounded keyword/synonym extraction attempt. Validated phrases feed the existing provider query planner; synonyms are OR alternatives within a concept, rather than additional required facets. An original-query pass is retained independently of the AI output. Missing AI, timeouts and malformed output keep original-phrase search available and show a concise fallback notice. AI-expanded terms never become hard exclusions.

Topic searches share provider selection, limits, backoff, progressive review, semantic ranking, cross-encoder ranking and optional relevance triage with related-paper discovery. Keyword intent appears in the review header. Repeating/refining a concept search keeps the original question and empty seed context, so changing the selected library paper does not redirect the search or contaminate its feedback. Searching does not import a paper; only explicit result selection changes the library. Regression tests cover both configured AI transports, single concepts/acronyms, bounded phrase validation, original-query retention, synonym grouping, cancellation, fallback, seed-free ranking and browser/API integration.

An author–year lookup first searches the selected paper's retained bibliography. PDF imports retain the reference-list tail separately from the 120,000-character working text, including when a PDF is added to an existing DOI record. The reference list and citation provenance survive save, export and recovery. Column-aware line ordering and bounded local English OCR improve native and scanned references; warnings identify incomplete extraction. Numbered and author–year entries, wrapped lines, accented surnames and named coauthors are supported conservatively. Year suffixes are read from the original reference; their order is never inferred. Missing or unparseable local references fall back to online author–year lookup. Unlabelled reference lists and complex layouts can require pasting the full reference.

Choosing a candidate calls `/api/metadata/citation/verify` before changing the library. A reference without a DOI first resolves its full title/reference metadata. The DOI record must agree with the DOI, title, first author, every explicitly named coauthor and an indexed publication year. Supplied initials, ORCIDs, journal/ISSN, volume, issue, pages and precise dates receive additional conflict checks. Crossref primary titles/subtitles and print/online dates are preserved to avoid false disagreements. Only verified records are added; failed candidates stay selected for correction or retry. Missing registry fields remain missing, with explicit verification diagnostics. No citation count or publication detail is fabricated. Metadata exports request identity verification for DOI records that have not passed it; ordinary local corrections remain protected by the existing metadata snapshot logic.

Transport keeps an in-memory circuit breaker per provider and hashed credential scope. HTTP 429 honors Retry-After (including dates); absent a delay, it pauses for 60 seconds. Two repeated server/connection failures start a 30-second backoff, growing to at most five minutes. Retry-After can extend a pause to one hour. Cached successful responses remain available, other credentials and providers continue, and a successful recovery clears the state. Local request budgets and cancellation do not count as outages. The state resets when the backend restarts; this is not a scheduled monitoring service. Public diagnostics contain provider labels, reasons and retry durations, without credentials or upstream response bodies.

Discovery publishes the first ranked 100 papers as providers return, throttling intermediate ranking without extending source deadlines. Large lists render the first 100 matching records and append further batches with Show next. Selection/bulk actions operate on the complete available result set. Stable identities preserve the focused preview, filters, scroll anchor, preview position and unchanged row nodes as results arrive and the final ranking completes. An explicit filter/sort change resets the result window. Papers absent from the final returned set cannot remain selected silently. Provider contributions are distinct-paper counts per provider and can overlap across indexes.

Regression checks cover bibliography-before-network behavior, a/b disambiguation, long PDF reference tails, DOI/title/author/date conflicts, complete metadata, source backoff/recovery, credential isolation, cache availability and local budgets. Real-browser tests reject a mismatched DOI before import and check stable row identity, selected preview and scroll position across streaming/final updates and paginated batches.

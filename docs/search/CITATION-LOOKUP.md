# In-text citations and DOI lookup

Paste an author–year citation into Add paper. Parenthetical and narrative formats, Unicode names, hyphenated/compound surnames, named coauthors, semicolon-separated groups (up to six), and year suffixes are recognized. A suffix such as `2026a` belongs to the originating bibliography; it does not identify an online record by itself.

Pulse queries [Crossref author search and publication-date filters](https://github.com/CrossRef/rest-api-doc/blob/master/api_tips.md) and [OpenAlex author-name and publication-year filters](https://help.openalex.org/api/searching/) concurrently. Provider text is untrusted, escaped before display, and paper links use normalized DOI URLs. Returned metadata must agree with the first author's surname, every named coauthor and exact indexed publication year. An `et al.` citation needs more than one indexed author. Both provider branches have a 12-second deadline; one source's failure preserves the other's candidates. Results are merged by bibliographic identity and show source provenance, titles, authors, journals and indexed DOIs. Optional title words refine the query.

Even a single result requires user selection: short author–year strings cannot prove global uniqueness. No guessed DOI or citation count is generated. Papers without an indexed DOI are explicitly identified. Crossref print/online publication-year differences, incomplete author lists, index coverage and author-name ambiguity can leave a genuine paper absent; paste its full reference or DOI to use existing full-metadata resolution.

The authenticated local endpoint is `POST /api/metadata/citation` with `{ "text": "(Martín-González et al., 2026)", "context": "optional title words" }`. Metadata resolution routes recognized short citations to the same flow. The picker supports refinement, keyboard cancellation, stale-response protection and selecting one candidate per citation. No library mutation occurs until Add selected.

A public live lookup of the example citation found multiple papers with indexed DOIs, confirming why selection is required. See [the recorded check](../../benchmarks/citation-lookup-live-check.json). Synthetic tests verify surname accents, compound boundaries, first-author/coauthor/year agreement, grouped/suffixed parsing, deduplication, partial-source handling and complete metadata retention. Browser tests verify no placeholder imports, selection, refinement, narrow layouts, cancellation and DOI identity on addition.

Discovery defaults to 500 displayed results and offers 1,000/2,000. Provider request caps, collection timeouts and neural ranking limits are separate from the display limit. Europe PMC follows [documented cursor pagination](https://europepmc.org/docs/EBI_Europe_PMC_Web_Service_Reference.pdf) using at most 1,000 records per page. The scoring pool is capped at 6,000 candidates and each retrieval branch at 3,000; larger result requests do not extend source deadlines or promise exhaustive retrieval.

    Mendeley

    Export your chosen citations, then import the file into Mendeley.
    Authorize Mendeley

    In Mendeley, drag in the downloaded RIS file, or choose Add New → Import Library → RIS. Import guide

    Direct transfers share bibliographic metadata and the abstract with the chosen manager. Export files stay on your Mac until you import them. PDFs and full paper text are not uploaded.

    Advanced connection settings

    For a custom Mendeley application, register in the Mendeley Developer Portal. Enter its client ID, secret, and exactly the same redirect URL here. Credentials stay in this Mac's protected Pulse settings.

Sync between your Macs

Keep the library, notes, tags, reading status and maps the same on each Mac. Everything is encrypted on this Mac with a key made from your sync code; Pulse’s relay stores only data it cannot read. PDFs, extracted full text and map positions stay on the Mac where they were made. Papers removed on another Mac can be restored from Recovery.

Sync is off.

Find it on your other Mac under Settings → Sync & privacy → Show code.

Anyone with this code can read and change your synced library. Keep it private, like a password.

Problem reports

When something goes wrong, Pulse records a report on this Mac: the error, where in the code it happened, app and macOS versions and memory use. Paper titles, notes, searches, keys and file paths are removed first. Nothing is sent unless you choose Send after viewing the exact report.
